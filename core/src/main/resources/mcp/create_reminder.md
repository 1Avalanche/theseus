Создать напоминание. Вызывай, когда пользователь просит о чём-то напомнить.

Время передавай так, как его сказал пользователь, в поле `when`: конкретная дата (`date`), время суток (`time`) или сдвиг от текущего момента (`after`). Никогда не вычисляй смещения таймзоны и UTC — это делает сервис. Пример: «через 5 минут» → `{"after": {"minutes": 5}}`; «завтра в 10» → `{"date": "<завтрашняя дата>", "time": "10:00"}`; «в 18:30» → `{"time": "18:30"}`.

Повторяющиеся напоминания пока не поддерживаются: поле `recurrence` не передавай.

Результат: `{"status": "created", "reminder": {...}}`. Ошибка — `{"error": {"code", "message"}}`; по `message` реши, нужно ли переспросить пользователя.
