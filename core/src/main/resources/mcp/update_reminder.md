Изменить текст или время существующего напоминания; заново задавать содержание не нужно. Сначала найди id через find_reminders. Для серии обязателен scope: series или occurrence. Новый час всей серии: scope=series, recurrence={"time":"19:00"}; поддерживается и when={"time":"19:00"}. Для occurrence укажи исходное occurrence_local (YYYY-MM-DDTHH:MM или только YYYY-MM-DD) либо ближайшее. Новый час when.time без даты сохраняет день выбранного срабатывания. Изменение расписания series сбрасывает исключения и отменяет будущие переносы: код агента запросит подтверждение последствий кнопкой. recurrence — частичный объект; null сбрасывает поле. Изменение только текста исключения сохраняет.
