Изменить текст/время найденного напоминания. У разового when.time или part_of_day без date/after сохраняет дату; не подставляй сегодня/завтра. Для серии нужен scope=series либо occurrence. occurrence_local — исходный момент; when.time без даты сохраняет день срабатывания. Час серии: recurrence={"time":"19:00"}. recurrence частичный, null сбрасывает поле. Сброс исключений/переносов — кнопкой.
