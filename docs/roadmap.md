## ⏳ Этап 2. Ходячий скелет
- Один сценарий сквозь всю систему: «напомни через 5 минут X» → tool call → core → Postgres → планировщик → уведомление в Telegram.
- Один пользователь (владелец), без инвайтов и онбординга, таймзона из конфига.
- Сразу деплой на VPS через docker compose: автоподъём после перезагрузки, потребление памяти.

## ⏳ Этап 3. Пользователи
