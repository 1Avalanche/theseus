# База данных

- PostgreSQL. Схемы: core — своя, agent — своя (история диалога). Каждый сервис мигрирует только свою схему.
- Flyway. Применённую миграцию **никогда не редактировать** — только новая. Изменения аддитивные: новая колонка nullable/с default; удаление/переименование — в два релиза.
- Время — `timestamptz` (UTC). Таймзона пользователя — IANA-строка (`Europe/Moscow`).
- Повторы — RRULE + IANA-таймзона + локальное время; следующее срабатывание считает код в локальной таймзоне.
- Каждая таблица с пользовательскими данными имеет `user_id` и индекс по нему.
- Статусы — enum в коде + check constraint в БД.
- Квоты заложены в схеме, по умолчанию выключены.
- Схема описана в `docs/database.md`; новая миграция — в том же изменении, что и правка этого документа.
- `created_at`/`updated_at` выставляет код через `Clock`, не `default now()`.
- Имена таблиц и колонок — понятными английскими словами, без аббревиатур из стандартов (`recurrence_rule`, не `rrule`). Связь со стандартом (RFC 5545 и т.п.) — в описании колонки в `docs/database.md`.
