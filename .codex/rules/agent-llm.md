# Агент и LLM

- Wire-контракт OpenRouter проверять по фактическому сериализованному HTTP-телу: `tools[].type` и `messages[].tool_calls[].type` обязаны содержать `function`. Значения по умолчанию Kotlin-свойств не должны исчезать из JSON; для wire-кодека включён `encodeDefaults`. Успешный `tools/list` MCP отдельно не доказывает передачу инструментов модели.
- Этап 2: свободный текст модели не подтверждает изменение и пользователю не выдаётся. Без вызова инструмента — `reply.not_created`; после попытки без подтверждения — `reply.unconfirmed`. Частично подтверждённые результаты сохраняются в ответе; модель не получает их для повторного создания. Произвольные уточнения и свободный диалог требуют отдельной безопасной реализации этапа 5.
