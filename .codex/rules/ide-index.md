# Поиск по коду: MCP-сервер индекса IDE

В IntelliJ IDEA установлен плагин MCP-сервера индекса IDE. Он даёт семантический поиск по индексу IDE — точнее и быстрее grep.

- Для навигации по коду **сначала** используй инструменты индекса IDE (`ide_*`):
  - где объявлено → `ide_find_definition`, `ide_find_class`, `ide_find_file`;
  - кто использует / вызывает → `ide_find_references`, `ide_call_hierarchy`;
  - реализации и иерархии → `ide_find_implementations`, `ide_type_hierarchy`, `ide_find_super_methods`;
  - текстовый поиск → `ide_search_text`;
  - ошибки компиляции/инспекций → `ide_diagnostics`.
- Переименование и безопасное удаление символов — через `ide_refactor_rename` / `ide_refactor_safe_delete`, а не ручной заменой текста.
- После массовых изменений файлов вне IDE — `ide_sync_files`, затем проверить `ide_index_status`.
- Grep/ripgrep — только как запасной вариант: сервер недоступен, проект не открыт в IDE, индекс не готов, или поиск по не-кодовым файлам (конфиги, Markdown, ресурсы).
- Предусловие: проект открыт в IDE. Если инструменты индекса не отвечают — сообщи об этом и переходи на grep, не повторяй вызов в цикле.
