# Настройка Codex

- Инструкции проекта загружаются из `AGENTS.md`; правила Markdown в `.codex/rules/` читаются по его таблице применимости.
- Навыки проекта находятся в `.agents/skills/`, определения субагентов — в `.codex/agents/`, хуки — в `.codex/hooks.json`.
- Не используй регистр `.Codex`: на файловой системе с учётом регистра это другой каталог.
- Не переноси `paths:`, `tools:`, `model: sonnet`, переменные `CLAUDE_*` и `worktree.bgIsolation` как настройки Codex. Область правил задаёт `AGENTS.md`, модель субагента — поле `model` в TOML (без него наследуется от родителя), работа идёт в текущей копии согласно `git-commits.md`.
- При запуске обычного субагента по файлу роли передавай её модель в параметрах запуска: текст инструкции модель не переключает.
- Проверки хуков и Gradle имеют отдельные отпечатки: Python-хуки и их тесты проверяются через `unittest`, код и ресурсы приложения — через Gradle; TOML ролей не относится к входам Gradle.
- Диагностика Codex в shell разрешена только точными командами `--version`, `-V`, `--help`, `-h`, `features list`; исключение не разрешает дополнительные аргументы или динамические подстановки.
