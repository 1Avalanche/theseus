# Тестирование

- Юнит-тесты обязательны для любой логики. Приоритет: domain и application (без инфраструктуры, быстрые).
- Даты и время: тесты с фиксированным `Clock`. Обязательные кейсы для расписаний — переход на летнее/зимнее время, конец месяца, 29 февраля, разные таймзоны пользователей.
- LLM в юнит-тестах не вызывается никогда — только фейк `LlmClient` с заранее заданными ответами/tool calls.
- Репозитории и миграции — интеграционные тесты на реальном PostgreSQL (Testcontainers), отдельно от юнит-тестов.
- Eval-набор LLM (реальные запросы к моделям) — отдельная задача, не входит в `./gradlew build`.
- Тест называется по поведению: `` `creates reminder in user timezone` ``.
- Не ослабляй и не удаляй существующие тесты, чтобы «позеленить» сборку. Если тест неверен — объясни почему.
