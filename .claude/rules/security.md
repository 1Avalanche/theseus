# Безопасность и изоляция данных

- **userId никогда не приходит из аргументов LLM.** Только из контекста запроса (заголовок/`_meta`, выставленный кодом агента). Каждый запрос в core фильтруется по userId.
- Каждый вызов core от агента — с сервисным токеном. core проверяет токен и что пользователь существует и активен.
- Сообщения от незарегистрированных chatId отсекаются **до** вызова LLM.
- Админские команды — только с chatId админа из конфига.
- Порт PostgreSQL наружу не публикуется. Бэкапы, уходящие за пределы VPS, шифруются.
- Секреты (Telegram token, OpenRouter key, service token, ключ шифрования бэкапов) — только env. Не логировать их и тексты сообщений пользователей на уровне INFO.
- Инвайт-коды: криптостойкий генератор, одноразовые, с TTL.
